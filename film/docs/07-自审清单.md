# 07　自审清单

没有人替你审的时候，每做完一版，按这张清单自己过一遍。它是从样板项目三轮美术审稿、几十条带坐标的修改意见，加上片子主人退回的十几处里归纳出来的。

用法：先用 `frames.py` 把全篇每秒截一张（`python3 kit/frames.py out/preview.html out/all/s 6 $(seq 0.5 1 62)`），再把每一处交接（落地、进窗、出窗、换姿态）前后 0.3 秒密截、放大 2–3 倍。对着截图一条条看。有问题的记下「第几秒、画布上大概什么位置、是什么问题」，再去改。

## A. 第一眼（0–3 秒）

- [ ] 打开的那一刻，画面是完整的吗？有没有东西悬在半空等着底下的线画出来？
- [ ] 标题、主角、主角色都在第一屏里吗？
- [ ] 3 秒内有没有一个动作发生？（闹钟响、角色跳）

## B. 碰撞（最常见的一类问题）

- [ ] 人有没有压在字上？下坠途中尤其要看。
- [ ] 字和字有没有叠在一起？
- [ ] 角色有没有挡住人的脸、挡住卡片上的字？
- [ ] 窗和窗、窗和小窗有没有互相压着？之间至少留 24。
- [ ] 有没有东西贴着页面边？离左右边至少 30–40。
- [ ] 线有没有从人的身体中间穿过去？（线索线、家具的线）
- [ ] 线和线有没有不该交叉的交叉？（窗框穿过窗帘）

## C. 重复和穿帮

- [ ] 同一个人有没有同屏出现两份？（下坠的她画进了窗里，而窗里的画面本来就有她）
- [ ] 换姿态的瞬间有没有两张图叠在一起的半透明重影？
- [ ] 叠加的道具和画面里本来就有的是不是重复了？（脚上有鞋又弹出两只鞋；头上有叶子又贴一片大的）
- [ ] 叠加的道具和画面里的同一个东西，大小和位置对得上吗？
- [ ] 抠图有没有少一块？（床帮、椅子腿、被挡住的手）封面也要看。

## D. 悬空和接触

- [ ] 站着、坐着、躺着的人，脚或身体是不是真的落在线上？有没有悬着一条缝？
- [ ] 放在家具上的东西，家具是不是和它同时出现？
- [ ] 掉下来的东西是不是落在地面线上，而不是线的下面？
- [ ] 两个抠图挨在一起时（人抱着角色、角色坐在人肩上），有没有谁压着谁的遮挡关系？只是并排摆着不算。
- [ ] 抠图的底边有没有漏到线下面的残渣？

## E. 空和等

- [ ] 有没有先露出来一个空框、一张只有表头的空卡片，然后让读者等？
- [ ] 有没有连续 2 秒以上屏幕里什么新东西都没发生？
- [ ] 推开有没有在某处停太久，然后一次推很远？（最重的那一下会发生在屏幕外）
- [ ] 推开顺不顺？有没有一顿一顿？

## F. 角色

- [ ] 它在画面里停着的每一秒，是不是都有一点动静？
- [ ] 它说话的时候有没有反应（蹦一下、耳朵动）？
- [ ] 全篇它的大小一致吗？列出每一处的显示宽度比一比。
- [ ] 每一帧都像它自己吗？手有没有被拉长、拉薄？脸有没有被转花？
- [ ] 睡着、生气、高兴这些状态，脸上有没有相应的变化（闭眼、耳朵耷拉）？

## G. 线稿

- [ ] 每一件线画的东西，是不是被某个厚涂的东西用着？纯摆设的一屏不超过一件。
- [ ] 近处的线比远处的粗一点、深一点吗？
- [ ] 线是在需要的那一刻画出来的吗？画的过程在屏幕里吗？
- [ ] 两个一样的小东西是不是太整齐了？
- [ ] 该加线的地方没加线？（人躺在一条光秃秃的横线上，其实那是沙发 / 床）
- [ ] 不该加的地方加了？（窗的四周、卡片旁边、已经很挤的下坠段）

## H. 字

- [ ] 最小的字不小于 18（750 坐标）吗？
- [ ] 夜段的字够亮吗？最后一句是不是用了正常字号？
- [ ] 每句对白停留够 1.2 秒吗？
- [ ] 重点信息（网址、品牌名）用的是全篇唯一的强调色吗？
- [ ] 有没有像下划线的破折号、像乱码的一串小字？

## I. 逻辑

- [ ] 时间标签连起来通顺吗？台词里提到的时间和标签对得上吗？
- [ ] 标签的用词合理吗？（早上九点的会，傍晚合电脑不能叫「散会」）
- [ ] 前面说了要做的事，后面有画面交代吗？
- [ ] 片子里有的关键动作，长图里有没有漏？对着场次表逐场核一遍。
- [ ] 那条线索线有头有尾吗？

## J. 颜色和明暗

- [ ] 人离开后压暗的窗，是「暗了一点」还是「褪色发白」？往回滑时还看得清吗？
- [ ] 柔光有没有一圈一圈的台阶？（层数不够）
- [ ] 两段底色的交界是干净的一刀吗？
- [ ] 补的地方（补洞、补背景）和周围是一个颜色、一个质感吗？有没有一块明显的色块？

## K. 技术（推之前）

- [ ] 循环动画里有没有对 `y` / `height` 的？（`grep -c 'attributeName="y"' out/article.html` 应该是 0；`height` 只允许不循环的）
- [ ] 每个带位移动画的元素都写了初始 `transform` 吗？（用 `K.track` 的自动有）
- [ ] 每张切片的图片数 ≤ 26，第一张更少？
- [ ] 正文 ≤ 640KB？
- [ ] 推上去以后，本地和草稿的标签数每一行都相等？
- [ ] 封面是用最新的画面截的？

## L. 交付前问自己三句

1. 对方上一次提的每一条，我是真的解决了，还是只动了一下？（把他圈出来的那个位置再截一张，和他的截图并排看。）
2. 我有没有为了省事改掉了他说过不能动的东西？
3. 哪些地方我只在电脑上看过？如实告诉他。

# 08　排错表

症状 → 原因 → 改法。按「在哪里出的问题」分组。

## 本地预览

| 症状 | 原因 | 改法 |
|---|---|---|
| 预览里图片全是空的 | `K.ASSETS` 没指到你的 assets 目录 | 脚本开头 `K.ASSETS = HERE / "assets"` |
| `没找到中文字体` | 系统里没有候选列表里的字体 | `K.init_fonts({"zh": "字体文件的路径"})` |
| 某些字没画出来，留了空 | 这个字体里没有那个字（生僻字、符号、emoji） | 换字体，或换一个说法；省略号用「……」别用「...」 |
| `量元素范围失败` | playwright 或 chromium 没装 | `pip install playwright && playwright install chromium` |
| 页面往下长到最后露出一截别的颜色 | 推开的 y 超过了画布高度 | `assemble` 已经会截断；检查 `H` 是不是比最后一幕的底小 |
| 某个东西一开始就在左上角闪一下 | 它的动画有初始位置之外的 `translate`，但元素本身没写初始 `transform` | 用 `K.track`；自己写的 `<g>` 加上 `transform="translate(起点)"` |
| 东西出现的时间不对 | `begin` 写成了相对时间；或关键帧的秒没递增 | 全部用绝对秒；`track` 的 keys 按秒排序 |
| 旋转时东西绕着奇怪的点甩出去 | body 不是以 (0,0) 为中心画的 | 用 `K.centered()`；自己画的东西把坐标平移到以 0 为中心 |
| 线画到一半就停了 | `draw_on` 的 length 比路径短 | 把 length 写大（多出来的没影响） |
| 下坠的人飞出页面左右 | `drift` 太大 | 减小；`fall_path` 中段已经把 x 限制在 150–600 |
| 换姿态时闪一下空白 | 两个姿态的时间段没接上 | `poses` 里上一个的结束秒 = 下一个的开始秒 |
| 截图上有一条横向细线 | 非整数缩放的截图假象，或者真的有缝 | `SCALE=3` 重截；还有就是切片接缝（见下） |

## 切片和体积

| 症状 | 原因 | 改法 |
|---|---|---|
| 每张切片里都多出同一个元素，动画数虚高 | 这个元素起飞前停在 (0,0)，量出来的范围从页面顶一直到终点 | 给它写初始 `transform`（见上） |
| 正文突然大了几十 KB | 一个大块元素（卡片、整段字）被切缝切到，两边各放了一份 | 调 `slice_target`（±100）换个切法；`slicer` 已经按字节数选缝 |
| 某张切片特别大 | 这一段转曲的字特别多 | 少几句；字号 ≥ 26 的汉字路径会取整，小字保留一位小数更占地方 |
| 接缝处有一条细线 | 手机上小数像素没对齐 | `slicer` 已经让每张往下多画 2 单位再用负 margin 收回；还有的话检查外层 `<section>` 是不是 `line-height:0` |
| 接缝处的东西上下错位 | 两张切片的宽度不一样（被编辑器加了 padding） | 外层 section 不要有 padding / margin；svg 用 `width="100%"` 和 `max-width:none!important` |

## 推草稿

| 症状 | 原因 | 改法 |
|---|---|---|
| `40164 invalid ip` | 出口 IP 不在白名单 | 把报错里的 IP 加进后台白名单；或 `export WX_PROXY=…` |
| `45002 content size out of limit` | 正文超过约 640KB | 见 docs/06 第 1 节 |
| 草稿里图片全裂了 | 没经过 `localize()`，href 还是本地路径 | 推之前调 `wxapi.localize()` |
| 标签数「草稿」比「本地」少 | 用了公众号不认的东西被删了 | 对照 docs/01 第 4 节；常见是 `xlink:href`、`<text>` 里的特殊属性、`<style>` |
| 草稿里中文变成 `一` 这样 | JSON 没用 `ensure_ascii=False` | `wxapi` 已处理；自己写接口时注意 |
| 传视频后拿不到 vid | 还在转码 | 等几分钟再跑；`upload_video` 会轮询 3 分钟 |
| 在后台编辑器里点开草稿再保存，动画没了 | 编辑器保存时会重新过滤内容 | 不要在后台编辑器里改这篇；要改就改脚本重新推 |

## iPhone 微信真机

| 症状 | 原因 | 改法 |
|---|---|---|
| 某一幕停在初始画面不动，别的幕正常 | 这张切片里有对 `y` 或 `height` 的无限循环 `<animate>` | 改成 `animateTransform`；不确定就跑 `phone_test.py` |
| 全篇都不动，只有第一屏有画面 | 没切片（单张巨型 SVG）；或第一张切片就有上面的问题 | 切片；查第一张 |
| 开头要等好几秒才动 | 第一张切片图片太多（图片全到齐动画才开始） | 减少第一张的图；角色立体帧用 `step=2` 减半 |
| 页面先往下长了，画面过一会儿才出来 | 推开没等图片 | `assemble` 已经在推开的 SVG 里放了全部图片的 1×1 隐藏引用；检查它有没有被删 |
| 中间某一幕出来得很晚 | 那张切片图片多、或有大图 | 压图；减帧 |
| 往下滑时很卡、手机发烫 | 同时在跑的循环动画太多，或图片太大 | 场景窗降到 2 帧、翻页放慢到每秒 0.8 帧；离开屏幕的幕没法停，只能减少总量 |
| 字发虚 | 用了 `<text>` 而不是转曲；或者字号太小 | 全部转曲；最小 18 |
| 颜色和电脑上不一样 | 微信深色模式会反色部分元素 | 每块底色都自己画一块实色矩形垫底，不依赖页面背景 |
| 安卓上正常 iPhone 上不正常 | 以上任意一条 | iPhone 更严，以它为准 |

## 画面效果

| 症状 | 原因 | 改法 |
|---|---|---|
| 人「贴」在画面上，不像在场景里 | 没有接触：悬空、没有影子、没有遮挡 | 身体压到线上；身下加接触线；加呼吸；让一样东西压在它上面 |
| 下坠像在坐电梯 | 匀速、直线、一个姿态到底 | `curve` 做快慢；`drift` 做弧线；途中换 2–3 个姿态并 `pop`；每 1–1.5 秒发生一件事 |
| 进窗时出现两个她 | 下坠的她画进了窗里 | 终点设在窗顶边上方 30，`op_out=0.2`；窗 `bounce` |
| 柔光有一圈圈的环 | `glow` 层数少 | `layers=28, op=0.012`（总亮度不变，层更多） |
| 压暗的窗像褪色的旧照片 | 往纸色洗得太多 | 纸白段 0.25、夜段 0.45 封顶 |
| 角色抬手像一片薄翅膀 | 手的抠图本来就是窄窄一条 | 不抬手；用耳朵、蹦、转头表现 |
| 角色转头时身上有白线 | 部位和身体之间露缝 | 部位多边形往身体里多圈几像素；`z` 调小 |
| 补的洞是一块明显的色块 | 用了纯色 | 用周围像素扩散补（只取同一种材质的像素），再加接触影 |
| 线画的家具和人不搭 | 线太粗、太实、和人之间有缝 | 线宽 1.3、透明度 0.75；人压在线上；线在人到的那一刻画出来 |

## 沟通

| 情况 | 做法 |
|---|---|
| 对方说「片子里那个镜头」而你不确定是哪个 | 把联系表上那几格截出来问「是这个吗」，确认了再做 |
| 对方说「没变化」「无效」 | 把他圈的位置和你改后的同一位置并排截出来看。多半是你改了表面（颜色、位置），没改他在意的那件事（遮挡、接触、形状）。先承认，再重做 |
| 对方问一个可以从上下文推出来的细节（标签写几点） | 自己定一个合理的，说明理由，不要反问 |
| 一条修改意见里有你拿不准会不会过头的（加个小装饰会不会太可爱） | 做一个最克制的版本，交付时单独说明「这一处我拿不准，不喜欢就去掉」 |
| 改动会碰到「不能动」清单里的东西 | 不做，说明原因，给一个不碰它的替代办法 |

# 04　写页面

对着 `kit/starter.py` 读这一份。下面的 `K` 都是 `import svgkit as K`。

## 1. 两个基本概念

**坐标**：画布宽 750，y 往下。手机一屏大约 1300 高。所有函数用的都是这套坐标。

**时间**：全篇一条绝对时间线。每个动画的 `begin` 都是「打开文章后的第几秒」，不靠滚动触发。好处是所有东西的先后是确定的；代价是读者不能自己控制节奏，所以要有「推开」。

**推开**：页面不是一次全露出来，而是按时间往下长。你维护一个列表 `REV = [(秒, 露出到的 y), ...]`，`assemble()` 会把它变成一张逐步变高的空白 SVG，把页面撑开。读者看到的效果是页面自己在往下滚。

```python
els, REV = [], []
add = els.append           # els 里的顺序 = 叠放顺序，后加的盖住先加的
...
article = K.assemble(els, H, REV, FIRST, "out", T=全片秒数)
```

## 2. 一幕的固定写法

```python
# ── 幕 N  名字（开始秒–结束秒）
Y = 上一幕的底 + 间距                 # 1. 这一幕在画布上的位置，用变量，不要写死数字
add(...)                               # 2. 往里加东西
REV.append((这一幕该露出的秒, Y + 这一幕的高 + 90))     # 3. 告诉推开
```

位置一律写成「相对上一幕」的（`WIN_Y = LINE1 + 1250`），这样中间插一幕、改一个高度，后面全部自动跟着走。写死绝对数字的话，改一处要改几十处。

## 3. 文字

```python
K.init_fonts()                                   # 开头调一次
K.text("往下掉的一天", 375, 118, 52, anchor="middle", spacing=0.12)     # y 是基线
K.say("它", "起来。", 40, 262, name_color="#6E9A5B")                     # 小字人名 + 正文
K.appear(K.say(...), 4.0)                        # 4.0 秒出现，从下面浮上来
K.show_once(K.text(...), 2.0, 5.0)               # 2 秒淡入，5 秒淡出
```

字号：对白正文 31，弱一点的回应 24，人名 20，时间标签 22，说明小字不小于 18（手机上 750 坐标的 18 约等于 9pt，再小看不清）。夜段文字用浅色（`night=True`）。

对白摆放：
- 说话的人在哪边，字就摆在他旁边空的那一侧。
- 跟着下坠的人走的对白：`x, y, *_ = pos(t)` 取她在那一秒的位置，摆在旁边 170 远处。y 取「她的 y − 40」「上一句 + 60」里更大的，避免两句叠在一起。
- 对白不要压在人身上，不要压进窗里，离页面左右边至少 40。

## 4. 图片、呼吸、柔光

```python
K.img("bed.png", x, y, w, h)                     # 普通放一张图
body, h = K.centered("mascot.png", 70)           # 以自己为中心的图，给 track 用
K.breathe(K.img("bed.png", 34, -bh + 3, bw, bh), LINE1)     # 以 LINE1 为底，纵向 1.2% 起伏
K.glow(cx, cy, 300)                              # 夜里一团暖光
```

`breathe` 里图的 y 要写成相对地面线的（`y − LINE1`）。躺着、坐着不动的人都加一个，3.2–3.6 秒一个来回，立刻不像贴纸。

## 5. 关键帧轨道 track：一切会动的东西

```python
keys = [(0, 64, 350, 1, 0, 1),        # (秒, x, y, 缩放, 角度, 透明度)
        (2.9, 64, 350, 1, 0, 1),
        (3.5, 650, 560, 1, 0, 1)]
add(K.track(body, keys))
```

- body 必须以 (0,0) 为中心（用 `K.centered`），这样缩放和旋转才绕它自己。
- 秒必须递增。两个关键帧之间是线性的；要抛物线就多打几个点（`K.hop` 帮你打）。
- 想让它在某一秒才出现：前一帧透明度 0，后一帧 1。
- `K.hop(p0, p1, t0, T, height=110)`：从 p0 跳到 p1 的一串关键帧，取 `[1:]` 接在已有的 keys 后面。
- `K.idle(keys, t0, t1, hops=(说话的秒,))`：原地等的那段时间里加一鼓一鼓和歪头，说话时蹦一下。要求 (t0, t1) 里原来没有关键帧。
- 落地：落点那一帧缩放 1.05 且 y 多 6（压扁），0.2 秒后回到 1。

## 6. 下坠

```python
start = dict(x=300, y=570, s=1.0, r=0)
top   = dict(x=WX + 400, y=WIN_Y - 30, s=1.0, r=0)       # 终点：下一个窗的顶边上方 30
keys, pos = K.fall_path(start, top, t0=6.5, T=4.0,
                        curve=[(0, 0, None), (0.3, 0.1, "in"), (0.8, 0.75, None), (1, 1, "out")],
                        drift=140, rot=lambda u: 20 * math.sin(math.pi * u * 2), bulge=0.1,
                        op_in=0.3, op_out=0.2)
body = K.poses([("fall_a.png", 190, 6.5, 8.5), ("fall_b.png", 250, 8.5, 10.6)])   # 按时间换姿态
add(K.track(body, K.pop(keys, pos, [8.5])))                                         # 换姿态时弹一下
REV += [(k[0], k[2] + 560) for k in keys[2::2]]                                     # 推开跟着她
```

调手感：
- `curve`：前 30% 的时间只走 10%（刚掉下去有点懵）→ 中间匀速 → 最后减速。全程匀速会像电梯。
- `drift`：让路径是一条弧线而不是直线。每次下坠换个方向（一次往右、一次往左）。
- `rot`：全程轻微摆动，或者中途翻一圈。
- `bulge`：中途放大 10%，有「掉向镜头」的感觉。
- 一次下坠 2.5–7 秒。途中每 1–1.5 秒发生一件小事（换姿态、接住外套、一句对白），否则就是一个人在白纸上滑。
- `REV` 的偏移量（560）决定她在屏幕里的位置：值越大她越靠屏幕上方。460–560 之间。

跟着她的东西都用 `pos(t)`：`x, y, s, r = pos(7.8)`，角色在 `(x − 150, y − 120)`，对白在旁边。

## 7. 线索线

```python
add(K.thread(keys))        # 在加人之前加，线画在人下面
```

一条细线从上一幕引到下一幕，随着她往下掉逐段画出来，线头落在她举起的那只手上。它让读者的眼睛知道往哪看，也是全篇的「一根线」。穿过硬边时把 keys 分成两段，夜里那段用浅色。**线头不要跟着身体旋转**，否则线会折成锯齿。落版处让这根线落进一个红点（或别的收尾），给它一个结束。

## 8. 场景窗

```python
add(K.window(WX, WIN_Y, 690, 388, "08:50 · 出门", ["win/day_0.jpg", "win/day_1.jpg"],
             t_on=10.45, frame_at=10.0, bounce=10.55, dim=(14.8, 0.25)))
add(K.catch_dust(WX + 400, WIN_Y, 10.55))
```

一个窗的一生：线框描出来（`frame_at`）→ 人落到窗顶边、淡掉 → 画面亮起（`t_on`）→ 整窗一沉一弹（`bounce`）、两侧溅四根短线 → 窗里的画面慢慢来回翻 → 人离开后盖一层底色压暗（`dim`）。

规则：
- **下坠的人不画进窗里**。窗里的画面本身就有她，再画一个就是两个她。让她在窗顶边上方 30 的地方淡掉（`fall_path` 的终点 + `op_out=0.2`），然后窗「接住」她。
- **框和图不要先露一个空的**。线框可以比图早 0.5 秒，但不能早几秒。
- 压暗：纸白段盖 0.25，夜段盖 0.45。不要压到看不清，读者会往回滑。
- 窗四周不加装饰：左右只剩 30，上面是时间标签，下面是对白，窗里已经很满了。
- 窗的时间标签（`"08:50 · 出门"`）全篇连起来要是一条通顺的时间线。

从窗里出去：下一次下坠的起点设在窗里她的位置，`op_in=0.2` 淡入。会有不到半秒的重影，可以接受；讲究的话把起点设在窗底边下方。

## 9. 厚涂 + 发丝线

这是让画面「贴合」的关键手法：人物和主要物件用抠图（厚涂），屋子里其余的东西用 1.2–1.4 粗的细线画，并且**在需要它的那一刻自己画出来**。

```python
add(K.ground(LINE1))                                                # 地面线，粗 2
add(K.draw_on(f"M{x0} {y} H{x1} M{x0} {y} V{LINE1} …", 420, 0.0, 0.4, INK, 0.8, 1.4))   # 路径、长度、几秒开始、画多久、颜色、透明度、线宽
add(K.sofa_lines(LINE2, 16.9, back=140))                            # 现成的一张沙发
```

路径怎么写：`M x y` 起笔，`H x` 横线，`V y` 竖线，`L x y` 斜线，`Q cx cy x y` 一段弧。一件家具就是几段横竖线加几个圆角。`length` 写大一点没关系，写小了线画不完。

什么能画、什么不该画（两条标准）：
1. **线画的东西要被厚涂的东西用着。** 柜子托着闹钟，沙发接住人，枕头垫着头，地面线接住鞋。纯摆设的，一屏最多一件（比如墙上的一扇窗）。
2. **那一屏已经有几样东西在动。** 下坠途中有人、角色、对白、线索线，再加就乱；开头结尾这种停下来的画面才有余地。

执行上的讲究：
- 线宽分层：近处的（柜子、沙发、拖鞋）1.3–1.4、深色、透明度 0.75–0.8；远处的（墙上的窗、窗帘）1.2、浅灰、透明度 0.5。
- 线和线不要互相穿过：窗框画到窗帘就停。
- 被线画的东西托着的物件，要和线同时出现。闹钟 0 秒就在，柜子 0.5 秒才画出来，这半秒闹钟是悬空的，而且是全篇第一眼。
- 人压在线画的家具上时要真的压住：身体下沿落在线上，身下的线往下弯 8–10，腿下加两三根短斜线当接触影。悬着一条缝就是「贴上去的」。
- 两个重复的小物件（一双拖鞋）不要一模一样，一只歪一点。
- 手稿感的东西不要填色；非填不可（枕头要垫住头）就降一点透明度。

## 10. 硬边和底色分段

```python
EDGE = WIN_Y + WH + 360
els.insert(0, f'<rect x="0" y="{EDGE}" width="750" height="99999" fill="{K.NIGHT}"/>')    # 插在最前面 = 垫在最底下
```

硬边上下各留 200 以上的空，让主线干净地穿过去。推开要保证她穿过硬边的那一刻硬边在屏幕里（在她到达之前 0.2 秒把 `REV` 推到 `EDGE + 200`）。夜段里所有线和字换成浅色（`NIGHT_TXT`、`NIGHT_LINE`）。

## 11. 砸下来、压扁、接住

```python
squash = '<animateTransform attributeName="transform" type="scale" values="1 1;1.05 0.86;0.98 1.04;1 1" keyTimes="0;0.3;0.7;1" begin="16.9s" dur="0.4s"/>'
add(K.show_once(f'<g transform="translate(375 {LINE2})"><g>{squash}{K.img("lying.png", -lw/2, -lh*0.72, lw, lh)}</g></g>', 16.9, None, fade=0.02))
```

下坠的最后一帧透明度 0，同一时刻换成落地姿态的图，以落点为支点压扁回弹 0.4 秒。同时让家具的线画出来、溅几根短线。三件事同一帧发生，才有「砸」的感觉。

## 12. 界面卡片

片子里的产品界面不要截图放进来（字太小、糊）。用矩形和文字重做一张：圆角白卡、表头、一行行内容。讲究：
- 卡片高度跟着内容长（这是少数可以对 `height` 做动画的地方：**不循环**、`fill="freeze"`）。不要先露一个大空框。
- 文字一行一行出现；想做「说的话飞进卡片」就给每个字一条轻量轨道，从说话人嘴边飞到它在卡片里的位置，前一行落定下一行再飞，路径不经过已经有字的行。
- 人从卡片后面过（先 `add(人)`，后 `add(卡片)`）。角色不要从卡片正面走过压住字。
- 卡片四周不画手稿线，否则它像一张贴纸。
- 样板里的写法见 `reference/example_build.py` 的 `app_card` 和 `example_build3.py` 幕 7。

## 13. 原片里的关键动作

片子里有、长图里没交代的动作（下班合上电脑、关门），抽原片 3–4 帧做成一个小一号的窗，放在对应的时间点，`loop=False` 播一遍停在最后一帧：

```python
add(K.window(40, LID_Y, 340, 191, "19:50 · 下班", [f"win/lid_{i}.jpg" for i in range(4)], t_on=38.6, fps=6, loop=False, dim=(40.4, 0.25)))
```

小窗放在主线旁边（她从窗的右边掉过去），不要挡住主线。原片里没有的动作才考虑用程序做，而且先确认对方说的是哪个镜头。

## 14. 结尾和落版

结尾停在一个安静的画面上：人和角色在一起，加呼吸、一个飘上去的「z」、一团暖光、两句对白。前面埋下的东西在这里交代（鞋摆好了）。之后可以接原片的视频（`tail` 里放 `{{VIDEO}}` 占位，推草稿时换成 `wxapi.video_iframe()`）和一块落版小 SVG（标志、一句话、网址）。落版是单独的一张 SVG，时间从它自己的 0 开始；重点信息（网址）用全篇唯一的强调色，字号不小于 32。

## 15. 生成和查看

```python
article = K.assemble(els, H, REV, FIRST, "out", T=全片秒数, tail="…")
```

会打印每张切片的元素数、图片数、动画数、体积，以及正文总大小。然后：

```bash
open out/preview.html
python3 kit/frames.py out/preview.html out/chk/a 5 0.5 2 3.5 5 6.5          # 读者视角
Y0=3600 HH=500 SCALE=2.4 python3 kit/frames.py out/preview.html out/chk/b 3 25.2 25.8 26.1   # 盯着一块放大看
```

每改一处就截那一处前后几个时刻。尤其是：两个东西交接的瞬间（落地、进窗、换姿态）前后各 0.1–0.3 秒密截。

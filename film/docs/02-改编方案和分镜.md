# 02　改编方案和分镜

## 1. 先把片子看成一张表

```bash
python3 kit/extract.py sheet 片子.mp4            # 整支片子，每秒 2 格
python3 kit/extract.py sheet 片子.mp4 30 20 4    # 第 30 秒起 20 秒，每秒 4 格（看细一点）
```

对着联系表列一张场次表：

| 场 | 片子里的秒 | 地点 / 时间 | 发生了什么 | 谁在 | 一句话的情绪 |
|---|---|---|---|---|---|
| 1 | 0–6 | 卧室，早上 | 闹钟响，她不起 | 她、它 | 赖床 |
| 2 | 6–11 | 卧室 | 它给她扎头发 | 她、它 | 被照顾 |
| … | | | | | |

片子里每一个有信息的镜头都要在表里，包括两三秒的过场（合上电脑、关门）。后面对方说「片子里那个镜头」时，你要能在这张表上指出来。

## 2. 四个要回答的问题

### 问题一：竖着往下的那条线是什么
片子靠剪辑把场次连起来，长图没有剪辑，只有「往下」。要找一个**物理上往下的动作**当主线，把各场戏串在上面。几种可用的线：

| 线 | 适合的片子 | 画面上是什么 |
|---|---|---|
| 人往下掉 | 一天 / 一段经历，节奏快，带点荒诞 | 人从上一场戏掉进下一场，空中换衣服、接东西 |
| 路 / 河 / 线往下走 | 旅程、成长、流程 | 一条路一直延伸，路边一站一站 |
| 东西往下落 | 产品、物件为主角 | 一个物件一路下落，沿途被加工、被使用 |
| 镜头往下摇 | 一栋楼、一个空间的不同层 | 楼层剖面，每层一场戏 |
| 时间刻度往下 | 纪实、日程 | 一根时间轴，刻度旁边长出画面 |

选的标准：这个动作在片子的主题里说得通（样板里是「忙到脚不沾地的一天」，所以人是真的一路在掉）。

### 问题二：哪些戏做成窗，哪些留给主线
- **场景窗**：把片子里的画面原样放进一个细线框。用在「有环境、有气氛」的戏：房间、会议室、车里、街景。
- **留白 + 主线**：两场戏之间，白纸上只有下坠的人、角色、对白和线。用在「转场、赶路、情绪」。
- **界面卡片**：片子里出现的产品界面，重做成一张真的卡片（文字是真字、能看清），不要截图。
- **整幅厚涂 + 线稿场景**：开头和结尾这种要停留的地方，人物用抠图压在一条地面线上，周围的家具用细线画。

一条经验：窗和留白要交替。连续三个窗会变成连环画；连续两段下坠会空。

### 问题三：底色怎么分段
最多两到三段。样板是纸白（白天）→ 一条硬边 → 深色（夜里）。分段的地方就是片子里最大的那次转折。交界用一刀切的硬边，不要做渐变（公众号里也做不了渐变），并且安排主线正好穿过它。

### 问题四：每一幕多久、多高
- 全篇 40–70 秒。超过 70 秒读者会滑走；片子里的时间按比例压缩，不用照搬。
- 一幕 3–6 秒。一句对白至少留 1.2 秒才看得清。
- 画布宽 750。一屏大约 1300 高（手机 375 × 650 左右）。一幕占 600–1200 高；下坠一段 800–1400 高。
- 全篇 6000–10000 高。

## 3. 分镜表

定完上面四件事，写成一张表。这张表就是代码的提纲，写得越具体，后面返工越少。

| 幕 | 秒 | 画布 y | 底 | 画面里有什么 | 对白（谁 / 第几秒） | 推开（第几秒露到哪） | 素材 |
|---|---|---|---|---|---|---|---|
| 0 题头 | 0–1 | 0–200 | 白 | 标题、副标 | — | 一开始露到 790 | — |
| 1 床 | 1–6 | 200–790 | 白 | 地面线 700；床和她（抠图）；闹钟；线画床头柜、窗；它蹲在床头 → 3s 跳上闹钟 | 它「起来。」3.5；她「五分钟……」4.0 | — | bed.png、clock.png、mascot.png |
| 2 窗 | 6–11.5 | 850–1250 | 白 | 场景窗：它给她扎头发 | 它「别动。」7.0 | 6.0 → 1340 | win/hair_0–3.jpg |
| 3 下坠 | 11.5–18.2 | 1250–2370 | 白 | 她从窗里出来往下掉，3 秒换外套、5 秒戴叶子；它跟着 | 它「外套。」14.5 … | 跟着她，露到她下面 560 | fall_a/b/c.png |
| … | | | | | | | |

写的时候顺手查：
- 每句对白出现时，说话的人在不在画面里？
- 每一幕露出来的那一刻，这一幕要看的东西是不是已经在了？（不能先露出一个空框）
- 最重的那一下（砸下来、穿过硬边、最后的拥抱）发生时，推开有没有让它在屏幕里？
- 时间标签前后对得上吗？（08:50 出门、「还剩七分钟」、09:00 开会）
- 前面说了要做的事（「我去收拾。」），后面有没有画面交代？

## 4. 没有美术指导的时候，方案怎么自己把关

样板项目里有一个专门审视觉的角色，每一版都给一份带坐标的修改清单。没有这个人，就自己分两次做：

**第一次：做方案时，强迫自己出三个不一样的方向再选。** 每个方向写三行：主线是什么、底色和线条什么样、最重的一下在哪。三个方向要真的不同（比如：人往下掉 / 一根时间轴 / 一栋楼的剖面），而不是同一个方向的三个配色。然后拿给片子的主人选，不要替他选。

**第二次：每做完一版，换一个身份看。** 隔一会儿，把预览从头放一遍，只做一件事：记下所有「咦？」的瞬间（看不懂、眼睛不知道看哪、有东西闪了一下、有字被挡住）。不要边看边想怎么改。看完再对着 `docs/07-自审清单.md` 逐条过。清单是从样板项目里几十条真实的修改意见归纳出来的。

**最有效的一招：找一个没看过片子的人。** 把预览发给他，什么都不解释，看他在哪里停住、在哪里往回滑。他停住的地方就是问题。

## 5. 和片子主人对齐的三件事（开工前问清楚，省得白做）

1. **哪些不能动**：剧情顺序、角色的样子、某几句台词。写下来，后面不再讨论。
2. **角色能不能重画**：通常不能。那就只能用他给的定稿图，做切件和立体帧（docs/05）。
3. **他提到某个镜头时指的是哪个**：指的几乎总是**片子里**的那个镜头。拿不准就把联系表上那几格截出来问「是这个吗」，不要按自己的理解先做一版。（样板里「合上电脑」被理解成了另一场戏里的另一台电脑，做了一版没用的。）

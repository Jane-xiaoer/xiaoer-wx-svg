# 05　角色怎么动

前提：主角色只有一张（或几张）定稿抠图，不能重画。在这个前提下有三档做法，从便宜到贵。先用便宜的，不够再往上。

| 档 | 能做到 | 代价 | 用在哪 |
|---|---|---|---|
| 一、整体关键帧 | 蹦、歪头、一鼓一鼓、落地压扁、翻滚 | 零（只加关键帧） | 全篇所有地方 |
| 二、切件 | 耳朵抖、手摆、脚点 | 每处多 4–6 张小图 | 角色停着的地方 |
| 三、立体帧 | 真的左右转头、眨眼、点头，加上第二档的全部 | 每个动作 6–12 张图 | 角色停着、而且是画面主角的地方（开头、结尾前） |

## 第一档：整体关键帧

```python
body, h = K.centered("mascot.png", 70)
keys = [(0, x, y, 1, 0, 1), (2.9, x, y, 1, 0, 1)]
keys += K.hop((x, y), (x2, y2), 3.0, 0.45, height=110)[1:]            # 跳过去
keys += [(3.5, x2, y2 + 6, 1.05, 0, 1), (3.7, x2, y2, 1, 0, 1)]       # 落地压一下
keys += [(6.4, x2, y2, 1, 0, 1)]
keys = K.idle(keys, 0.0, 2.9, period=1.3)                              # 等着的时候一鼓一鼓、歪头
keys = K.idle(keys, 3.7, 6.4, period=1.1, hops=(4.0, 5.5))             # 说话的那两秒各蹦一下
add(K.track(body, keys))
```

要点：
- 角色**任何时候都不该是一张静止的图**。只要它在画面里停超过 1 秒，就加 `idle`。
- 它每说一句话，蹦一下（`hops`），读者就知道是它在说。
- 跟着人下坠时，位置用 `pos(t)` 加偏移，角度给一个 `12 * sin(t * 3)` 之类的摆动。
- 和别的东西互动（按住一片叶子、拽毯子）：在那一秒把它的位置移到那个东西旁边，同时让那个东西的轨道也动。

很多情况下做到这一档就够了。

## 第二档：切件

把抠图切成身体 + 耳朵 + 手 + 脚，各自绕一个转轴小幅转动。全部由 `character.py` 按一份配置做。

```bash
cp kit/rig.example.json rig.json
python3 kit/extract.py grid assets/mascot_src.png      # 生成带坐标网格的大图，对着它量
# 编辑 rig.json：每个部位的多边形 poly、转轴 pivot
python3 kit/character.py parts rig.json                # 生成 mascot_parts.png 检查图
```

检查图有三格：左 = 切完的身体（缺口处该补色的补了没有）；中 = 拼回去（应该和原图一模一样）；右 = 每块转 25 度（看有没有露缝、转轴对不对）。

写 rig.json 的要点（字段说明在 `character.py` 开头）：
- `is_body`：一句能把身体主色挑出来的表达式。绿色身体：`(g > r + 12) & (g > b + 25)`。先在取色器里看几个点的 RGB 再写。
- 耳朵这种**颜色和身体不同、长在轮廓外面**的，用 `"mode": "color"`：多边形圈大一点，只取里面「不是身体色」的像素。
- 手、脚这种**和身体同色**的，用 `"mode": "cut"`：多边形里的全拿走；`fill` 写一句话说明切走以后身体上哪些位置要补成身体色（靠里的一侧补，靠外的留空）。例：左手在 x 0–30，身体从 x=25 开始，就写 `"x >= 25"`。
- 转轴放在这个部位和身体连接的地方：耳根、肩、脚踝。

切件可以直接在 SVG 里用（每块一个 `<image>`，外面包 `<g>` 做 `animateTransform rotate`），幅度控制在：耳朵 ±15°、手 0–15°、脚 0–15°。更常见的是继续做第三档，把切件当成立体模型的零件。

## 第三档：three.js 立体帧

原理：把每一块抠图当成贴图贴在一张细分的平面上，再按一张「厚度图」把平面往前顶成鼓起来的形状（离轮廓越远越厚、边缘是圆的）。这样角色有了体积，可以真的转头、点头；因为颜色直接取自贴图、不打光，画出来还是原来的笔触。在无头浏览器里把每个姿态渲染成一张透明 PNG，页面里按帧翻。

```bash
# rig.json 里再填 eyes（两只眼睛中心的坐标）、actions（动作表）、stills（单帧）
python3 kit/character.py render rig.json
# → assets/mascot3d/mascot_idle_0.png … 以及 assets/mascot_actions.png（动作联系表）
```

**渲染完先看联系表**，每一帧都要像它自己。然后在页面里用：

```python
import character
body, h = character.svg_frames("mascot", 74, acts=[("talk", 3.5, 4.25), ("stomp", 5.0, 6.2)], assets_dir="assets")
add(K.track(body, keys))        # 位置、蹦跳仍然由第一档的关键帧管
```

平时循环播 `idle`；`acts` 里的时段换成指定动作。`step=2` 让 idle 只用一半的帧。

### 动作怎么设计

一个姿态是一组数：`ry` 左右转头、`rx` 点头、`rz` 歪、`by` 整体上下、`sq` 压扁、`blink` 闭眼，以及各部位的角度。样板里用的三个动作（都在 `rig.example.json` 里，可以直接改）：

- **idle（12 帧，每秒 6 帧，2 秒一圈）**：头慢慢转到一边、停一下、转回来、转到另一边；途中眨两次眼、每只耳朵各抖一次；手跟着呼吸微微张合。转头不要匀速摆，要「转过去 → 停 → 回来」。
- **talk（6 帧，每秒 8 帧）**：身体往前倾一点，蹦两下，两只耳朵跟着扇。
- **stomp（4 帧，每秒 12 帧）**：左右晃着轮流抬脚，落地那帧压扁一点，耳朵一抖。
- **sleep（单帧）**：闭眼，两只耳朵往两边耷拉 48°。用在睡着的地方，非常出效果。

### 踩过的坑

- **手不要抬高。** 抠图里的手通常是贴着身体的一小条，抬到水平就是一根细棍，再拉粗就成了一片薄翅膀，怎么调都不对。手只在 0–20° 之间小幅动。要表现「说话」「兴奋」，用蹦、耳朵扇、转头、眨眼。
- 转头别超过 ±22°，再大侧面的贴图就拉花了。
- 部位的 `z`（离身体多远）不要大：耳朵 3、手 4、脚 18。大了转头时部位和身体之间会露出缝。
- 身体上切走部位留下的缺口，脚本会往里多留 7 像素并把透明处的颜色填成邻近色；如果转头时还是露白线，把那个部位的多边形往身体里再圈 2–3 像素。
- 眨眼是着色器画的一道弧，是唯一不来自原图的一笔。眼睛坐标要准；闭眼那帧要放大检查。事先告诉片子主人这一笔是程序画的。
- 渲染需要能访问 jsdelivr（加载 three.js）。不能上网就把 three.module.min.js 下载到本地，改 `character.py` 里 importmap 的地址。

### 图片数的账

每一帧是一张图。idle 12 + talk 6 + stomp 4 = 22 张，一处就占掉一张切片大半的图片额度。所以：
- 只在角色停着被看的地方用立体帧（开头、某个它站在显眼位置说话的地方）。
- 下坠途中、跟在人后面的时候，用普通抠图 + 第一档。
- 跨切片移动的角色（从一张切片跳到另一张）会被两张切片各收一份，图片数翻倍。让用立体帧的那段尽量待在一张切片里。

## 角色的一致性

- **大小**：全篇同一个角色显示宽度差别不超过 15%（样板：站着 70–82，跟着下坠时 60–64）。每加一处先看别处是多少。
- **朝向**：定稿图是正面的，就别在某一处突然用一张 3/4 侧面的。
- **和人的比例**：对照片子里它站在人旁边的镜头，量一下它是人头的几倍。

## 让它被抱着（两张抠图要有遮挡关系）

只把角色摆在人的图前面，怎么调位置和颜色都像贴上去的。要让它「在怀里」，必须有东西压在它身上：

1. 把抱着它的手从人物图里切出来（按肤色选区），绕手腕转 10–20°，让手指搭到角色身上。
2. 手原来的位置，用周围的颜色往里扩散补上（只取衣服的像素，不取皮肤）。
3. 人物图里臂弯的空洞，同样用衣服的颜色补，再压一圈角色的接触影（角色轮廓模糊后变暗 30%）。不要垫一个纯色的圆。
4. 下面那只手臂单独切一层，盖在角色的脚上。
5. 叠放顺序：补好的底图 → 角色 → 下臂 → 两只手。

样板的实现在 `reference/hug_fill.py`（坐标是样板那张图的，思路可以照搬）。验收标准只有一条：**能指出至少两处「人的某个部位压在角色上面」**。

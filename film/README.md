# 片子改编：视频 → 公众号 SVG 动效长图

把一支横屏、按时间播的片子，改编成公众号里竖屏、打开就自己往下演的一张长图：人从片子的第一场戏一路「掉」到最后一场，掉进一个个场景窗，窗里是片子里的画面，窗外是白纸、细线和对白。读者不用滑，页面按时间自己往下长。

做成的样子看样板：《小耳和阿卡的一天》，13 幕、62 秒、画布 750 × 9300。

## 第一次用：先跑通起步工程（10 分钟）

```bash
pip install pillow numpy scipy fonttools playwright
playwright install chromium
cp -r film/kit 我的项目/kit && cd 我的项目/kit
python3 starter.py                 # 生成 out/preview.html
open out/preview.html              # 双击也行；点「重播」从头看
python3 frames.py out/preview.html out/chk/a 5 0.8 3.3 5.6 8.6 10.6    # 截 5 个时刻拼成一排
```

看到一张床、一只小方块从床头跳到床头柜、人掉下去被一个窗接住、再掉进一张线画的沙发，就是通了。占位图很丑，那是故意的：`starter.py` 里的四幕就是四种最常用的写法，之后把占位图换成你的素材、照着改。

## 做一支真的：七步

每一步的细节在对应的 docs 里。这里只说做什么、做到什么算完、最容易错在哪。

### 第 1 步　准备（docs/01）
装好依赖和 ffmpeg；找一个中文字体文件；公众号拿到 AppID / AppSecret，把本机出口 IP 加进白名单。
**做完的标志**：`python3 starter.py` 能出预览；`python3 -c "import wxapi; print(wxapi.token()[:8])"` 能打出东西。

### 第 2 步　看片、定改编方案、写分镜（docs/02）
把整支片子拼成联系表看一遍，列出场次。然后回答四个问题：竖着往下的那条线是什么（谁在掉、掉进什么）；哪几场戏做成场景窗；底色怎么分段；每一幕几秒到几秒、画在哪。写成分镜表。
**做完的标志**：一张分镜表，每一行有「秒、y 范围、画面里有什么、对白、推开到哪」。分镜没定之前不要写代码。
**最容易错**：把片子按顺序切成图往下排。那只是连环画，不是改编。

### 第 3 步　取素材（docs/03）
场景窗的帧（每窗 2–4 张，600 × 337 的 JPG）、人物姿态的抠图、主角色的抠图、道具。全部压到够小。
**做完的标志**：`assets/` 里的文件名和分镜表对得上；单张图不超过 1MB；透明图量化到 256 色。
**最容易错**：凭记忆猜镜头在第几秒；抠图把被挡住的部分抠掉了没发现（床少一截）。

### 第 4 步　写页面（docs/04）
照 `starter.py` 的结构，一幕一段。每一幕：定这一幕的 y → 加东西 → 往 `REV` 里加「几秒露出到哪」。
**做完的标志**：`python3 你的build.py` 出预览，从头到尾能看完，每一幕都在该露出的时候露出。
**最容易错**：循环动画用了 `y` 或 `height`（电脑上好好的，iPhone 上整张不动）；带位移动画的元素没写初始位置（切片后每一张里都有它）。

### 第 5 步　让角色活（docs/05）
先用关键帧（`idle`、`hop`）。不够再切件。还不够再上 three.js 立体帧。
**做完的标志**：角色停着的时候不是一张死图；全篇大小一致；动作联系表上每一帧都像它自己。
**最容易错**：让手抬起来（会被拉成薄片）；每处都用立体帧（图片数爆掉）。

### 第 6 步　自己看、自己挑（docs/07）
每改一次，用 `frames.py` 把改到的地方截出来放大看，再对着自审清单过一遍。有条件的话找一个没看过片子的人从头看一遍预览，记下他在哪儿停顿、哪儿看不懂。
**做完的标志**：清单上没有打叉的；截图里没有叠在一起的字、悬空的东西、两个同样的人。

### 第 7 步　切片、推草稿、真机验（docs/06）
`assemble()` 自动切片并报正文大小；`--push` 传图存草稿并核对标签数；截封面；从公众号后台发预览到自己的手机，**用 iPhone 微信从头看到尾**。
**做完的标志**：手机上每一幕都在动，开头两秒内启动，没有哪一幕停在初始画面。
**最容易错**：电脑上能播就当成了。电脑浏览器、模拟器都不算数，只有真机算。

## 五条铁律（每条都是整天整天踩出来的）

1. **循环动画只用 `opacity`、`transform`、`stroke-dashoffset`。** 对 `y` / `height` 做无限循环，iPhone 微信里那一整张 SVG 都不动。
2. **长图必须切片，而且每张的图片数要少。** 一张 SVG 里的图片全部加载完，它的动画才开始；第一张尤其要少。
3. **正文不超过约 640KB。** 超了存草稿报 45002。每次生成都看一眼打印出来的大小。
4. **主角色不重画。** 只用定稿的那张图切、转、顶成立体。重画出来的不是它。
5. **改完自己截图看过，才能说改好了。** 说「改了」之前先确认问题真的没了；只换了颜色、没解决遮挡关系，不算解决。

## 交付时怎么说

先说状态：推到草稿了没有、在哪里看过（电脑截图 / 真机）、哪些没验。再逐条说对方提的每一点改成了什么。没做的、有代价的、自己拿不准的单独列出来，不要藏在后面。只存草稿，发布永远留给号主自己点。

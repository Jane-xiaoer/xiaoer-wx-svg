# 01　环境和账号

## 1. 装什么

| 东西 | 干什么用 | 怎么装 |
|---|---|---|
| Python 3.9+ | 跑所有脚本 | 系统自带或 python.org |
| pillow、numpy | 处理图片 | `pip install pillow numpy` |
| fonttools | 把字转成曲线 | `pip install fonttools` |
| playwright + chromium | 无头浏览器：量元素范围（切片）、截图自查、截封面、渲染角色 | `pip install playwright && playwright install chromium` |
| scipy | 角色厚度图、补洞（只有第 5 步用到） | `pip install scipy` |
| ffmpeg | 从片子里抽帧 | macOS `brew install ffmpeg`；Ubuntu `apt install ffmpeg`；Windows 从 ffmpeg.org 下载后加进 PATH |
| rembg（可选） | 自动抠图 | `pip install rembg`。没有也行，用任何抠图工具（Photoshop、remove.bg、剪映）抠成透明底 PNG |

装完跑 `python3 kit/starter.py`，能出 `out/preview.html` 就是好了。

## 2. 字体

公众号正文里不能加载自定义字体，`<text>` 在每台手机上长得不一样，所以**所有字都转成曲线**（`svgkit.text()`）。你需要一个字体**文件**：

- `svgkit.init_fonts()` 不传参数时会自动找系统里的中文字体（macOS 的宋体 / 黑体、Windows 的楷体 / 雅黑、Linux 的 Noto / 文泉驿）。
- 想指定：`K.init_fonts({"zh": "/路径/正文.ttf", "title": "/路径/标题.ttf"})`，之后 `K.text("字", x, y, 31, "title")`。
- 推荐霞鹜文楷（LXGW WenKai，开源可商用），手写感和线稿很搭。
- 商用要注意字体授权：系统自带字体不一定能商用，开源字体（霞鹜文楷、思源宋体 / 黑体）可以。

转曲的代价是体积：一个 31 号的汉字大约 0.3–0.6KB。全篇对白控制在 300 字以内没有问题；大段正文不要转曲，也不适合放在这种长图里。

## 3. 公众号这边要准备的

1. **类型**：服务号或已认证的订阅号才有完整的素材和草稿接口。个人未认证订阅号很多接口没权限，这时只能手动：把 `out/article.html` 里的内容通过第三方编辑器或浏览器开发者工具贴进后台编辑器（不保证不被过滤）。
2. **AppID 和 AppSecret**：公众号后台 → 设置与开发 → 基本配置（新版在「开发接口管理」）。AppSecret 只显示一次，存好，**不要写进代码、不要提交到仓库**。
3. **IP 白名单**：同一页。把你跑脚本这台机器的**出口 IP** 加进去。
   - 查出口 IP：`curl ifconfig.me`。
   - 用了代理的话，接口看到的是代理的出口 IP。报 `40164` 时错误信息里会写它看到的 IP，把那个加进白名单最省事。
   - 家用宽带 IP 会变，变了就要重新加。
4. **环境变量**：
   ```bash
   export WX_APPID=wx1234567890abcdef
   export WX_SECRET=你的AppSecret
   export WX_PROXY=http://127.0.0.1:7890     # 可选：只让公众号接口走这个代理
   ```
   验证：`cd kit && python3 -c "import wxapi; print(wxapi.token()[:8], 'ok')"`

## 4. 公众号正文里能用什么、不能用什么

能用：
- 内联 `<svg>`，里面的 `rect / circle / line / path / image / g`。
- SMIL 动画：`<animate>`、`<animateTransform>`、`<set>`，`begin` 可以是秒数，也可以是 `click`（点一下触发）。
- `<image href="https://mmbiz.qpic.cn/...">`：只认公众号自己的图床地址，所以图要先上传（`wxapi.localize()` 自动做）。
- 外层 `<section style="...">` 的内联样式。

不能用（会被删掉，或者整段失效）：
- `id` 属性、`<style>` 标签、`class` 选择器、JavaScript。
- `<mask>`、`<clipPath>`、`<filter>`、`<linearGradient>` / `<radialGradient>`。
- `xlink:href`（要写 `href`）。
- 对 `fill-opacity` 做动画（对 `opacity` 可以）。
- 外链图片、外链字体。

没有渐变和滤镜怎么办：柔光用很多层半透明的圆叠（`svgkit.glow()`）；压暗用一块底色矩形盖上去调透明度；需要裁切就把图预先裁好。

## 5. iPhone 微信比别处更严的地方

电脑浏览器、安卓、iPhone 模拟器都能播，只有 iPhone 微信真机会坏的写法：

| 写法 | 后果 | 改成 |
|---|---|---|
| `<animate attributeName="y" …repeatCount="indefinite">` 或对 `height` 无限循环 | 这一整张 SVG 的动画都不启动，停在初始画面 | 外面包一层 `<g>`，用 `animateTransform type="scale"` 或 `translate` |
| 一张 SVG 几千高、几百个动画、几十张图 | 不启动或极卡 | 切片，每张 800–1000 高 |
| 同一个图片地址在一张 SVG 里出现多次 | 有的请求不结束，这张 SVG 不启动 | 每处地址后面加不同的 `?v=n`（`wxapi.localize()` 自动加） |
| 一张 SVG 里图片很多 | 图片全部加载完动画才开始，所以启动很晚 | 每张切片控制图片数（实测 26 张能跑，越少启动越快） |

`skewX`、`animateMotion` 没在真机上验过，先别用。非循环的 `height` 动画（播一遍停住）实测可以。

## 6. 目录怎么摆

```
我的项目/
  kit/                从 skill 里拷来的工具包
  片子.mp4
  assets/             所有图片素材
    win/              场景窗的帧
    <角色>3d/         角色的立体帧
  build.py            你的主脚本（从 kit/starter.py 改）
  out/                生成的东西：preview.html、article.html、long.svg、cover.jpg、mmbiz.json、media_id.txt
  work/               中间文件、旧版本备份
  分镜.md
  交接.md             每一批改了什么、为什么、没做什么
```

每次大改之前把 `build.py` 复制一份到 `work/`（带上日期或批次）。这种页面改起来牵一发动全身，回不去很痛苦。
